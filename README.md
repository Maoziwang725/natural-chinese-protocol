# 自然中文协议 Natural Chinese Protocol

很多人都注意到，AI 大模型写中文有一堆稳定的毛病。比如说喜欢三段式排比，在每句判断后面找补一句，把"是"写成"扮演着……的关键角色"，结尾永远"挑战与机遇并存"。这些毛病偶尔冒出一两条问题不大，堆在一起就不像人写的了。

举个例子，让模型写一段产品介绍，大概率会出来这样的东西：

> 新一代智能手表的发布，标志着我们在可穿戴设备领域的深度赋能。它不仅提升了续航能力，优化了监测精度，更重塑了用户的健康管理闭环。值得注意的是，这无疑是一款绝对能引领潮流的产品。未来依然可期。

三段排比、一个"无疑"、一个"绝对"、一个"值得注意的是"、一个"未来可期"结尾。五个毛病挤在四句话里。

这份协议把这些模式逐条拆开，告诉你的模型如何辨认语病和自检。这个 skill 可以直接作为 prompt 使用。

## 用法

协议正文在 `SKILL.md`，纯 Markdown，跟平台和模型无关。

**直接当 prompt 用。** 复制 `SKILL.md` 全文，粘到任意模型的对话框里，后面接上要改的文本。

**写进长期指令。** 多数 AI 工具有某种持久化配置（系统提示词、自定义指令、项目级配置文件），把协议正文放进去，以后不用每次粘。

**自己写完中文以后对着查。**

**Claude Code 用户。** 一条命令装完自动生效：

```bash
git clone https://github.com/Maoziwang725/natural-chinese-protocol ~/.claude/skills/natural-chinese-protocol
```

只想对某个项目生效的话，把 `~/.claude/skills` 换成那个项目下面的 `.claude/skills`。

## 协议管辖范围

只管语言层面，也就是"这段话像不像人写的"。事实对错、逻辑通顺、专业内容是否成立，都不在管辖范围内。改完了该核对的还得核对。

不做跨文体改写。不会把公文改成大白话，反之亦然。协议第一步就是先判断场景，定好语域再动手。

不追求"越短越好"。市面上不少去 AI 味的方案会滑向另一个极端，把句子切成一顿一顿的短句，读起来像电报。那同样不像人说话，只是怪异感变了一点。协议里专门留了一条，要求保持句子正常的延展度和合理的连词。

v2.0.0 新增了一套学术论文叙事策略，针对写论文、改论文、组织实验叙事的场景。核心思路是把论文当学术报告来组织，围绕真正的优势搭建叙事线，不写成工作汇报，也不替审稿人攻击自己。

词表会过时。黑名单里的词是当下这一批模型的高频习惯，模型会更新，流行语也会变。这份清单需要跟着维护，发现某条规则执行过头或者没触发，欢迎提 issue。
